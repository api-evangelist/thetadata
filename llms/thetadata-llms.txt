# ThetaData

> Developer-first US market data vendor: real-time and historical options, stocks, indices, and interest-rate data with unfiltered tick-level trades, quotes, and Greeks. Data is served by the Theta Terminal, a local Java application exposing a local REST API (http://127.0.0.1:25503/v3), a WebSocket streaming API (ws://127.0.0.1:25520/v1/events), and an MCP server (http://127.0.0.1:25503/mcp/sse) — or directly via the official Python library (pip install thetadata, HTTPS auth + gRPC data, no terminal needed).

Generated by API Evangelist from the ThetaData catalog entry and repo artifacts (2026-07-22); ThetaData publishes no /llms.txt of its own.

Key facts for agents:
- All 66 v3 REST operations are HTTP GET reads — idempotent, safe to retry.
- Auth is session-level (API key or account credentials at Theta Terminal launch / ThetaClient construction), not per-request; the OpenAPI declares security: [].
- No pagination: v3 returns single-query responses; keep responses under ~1M ticks (see Request Sizing).
- Errors are plain text with custom HTTP codes (471 PERMISSION, 472 NO_DATA, 474 DISCONNECTED, 570 LARGE_REQUEST...).
- Concurrency-limited (FREE 1 / VALUE 2 / STANDARD 4 / PRO 8, account-wide), not rate-limited; free tier is 20 req/min.
- Output formats: format=csv|json|ndjson|html; expiration/strike accept * wildcards.

## APIs
- [REST API v3 docs](https://docs.thetadata.us/): stock, option, index, interest-rate, calendar endpoints (list / snapshot / history / at_time / flat_file)
- [OpenAPI 3.1 spec (source of truth)](https://docs.thetadata.us/openapiv3.yaml)
- [Streaming WebSocket API](https://docs.thetadata.us/Streaming/Getting-Started.html): QUOTE/TRADE/STATUS JSON messages at ws://127.0.0.1:25520/v1/events
- [MCP server](https://docs.thetadata.us/Mcp/Getting-Started.html): built into Theta Terminal v3, SSE at http://127.0.0.1:25503/mcp/sse (Claude CLI: `claude mcp add --transport sse ThetaData http://127.0.0.1:25503/mcp/sse`)
